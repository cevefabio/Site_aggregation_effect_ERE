# Output directory

The analysis scripts create subdirectories here for model objects, bootstrap
results, welfare simulations, tables, and figures.

`reference_outputs/` contains fixed copies of the figures and tables used in
the submitted paper, together with the submitted appendix. These files allow
replicators to compare newly generated results with the reported outputs. The
analysis scripts write outside `reference_outputs/` and do not overwrite these
copies.

The main README lists each paper output, the script that produces it, and its
archived reference file.
